# ATMA STARTER — Project Instructions

## Project

This is a custom WordPress theme called **Atma Starter**.

The goal is to build a reusable, minimalist theme for therapists and personal brands.

## Rules

- Preserve the existing HTML structure unless explicitly asked.
- Never change CSS classes without permission.
- Do not redesign sections unless requested.
- Use PHP compatible with WordPress standards.
- Keep all reusable sections inside `template-parts/`.
- All editable static content should use the WordPress Customizer (`get_theme_mod`).
- Dynamic collections (Testimonials, Blog) should use Custom Post Types.

## Naming

Use the `atma_` prefix for every Customizer field and function.

Examples:

- `atma_hero_title`
- `atma_offer_image`
- `atma_contact_phone`

## Design

- Minimal Scandinavian style
- Warm beige palette
- Rounded corners
- Plenty of whitespace
- Typography must remain elegant and readable

## Workflow

Before making changes:

1. Keep the current design.
2. Modify only the requested section.
3. Do not touch unrelated files.
4. Return complete code only for changed fragments.
