# Atma Starter – AI Development Guide

## Project structure

- WordPress (LocalWP)
- Hello Elementor = parent theme
- Atma Starter = child theme
- Elementor = page builder

## Never modify

- wp-admin/
- wp-includes/
- hello-elementor/

## Modify only

- .
- assets/
- inc/
- template-parts/

## Coding rules

- PHP 8.2+
- WordPress Coding Standards
- No inline CSS if possible
- Separate PHP, CSS and JavaScript
- Mobile first
- Reusable components
